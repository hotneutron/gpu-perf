## Resource policy

- The GPU-7-only schedule is superseded by all dedicated matching idle H100s.
  A point and all of its native repeats remain bound to one physical device.
- Current GPU availability is dynamic; the stored snapshot is not a lease.
  Zero utilization with a foreign context does not qualify as dedicated.
- CPU-only GCoM replay does not consume a GPU lease. Use disjoint CPU sets and
  `workers × OpenMP threads` within the actual available budget; 24 × 8 is a
  192-CPU capacity example, not a fixed worker count.
- Protect GPU timing host cores and observe RAM/disk limits before scaling.
  Identical replay fingerprints still execute once; aliases reuse results.

## Preflight gates

- A present binary is not a qualified build. The source README documents CUDA
  11.4/12.8 and static libraries; the previous executable is CUDA 13.3/shared
  cudart. Record pilot compatibility or a separately qualified realization.
- A trace replay is not a simulator-side numerical check. Native oracle checks,
  complete trace structure and GCoM timing admission are distinct.
- The previous native labels measure stream program spans. Last-kernel cycles
  or summed kernel bodies cannot silently inherit that label or its eligibility.
- No identical GCoM replays, hidden TMA compatibility flags, inferred H3
  references, post-hoc gate cutoffs or simulator retuning.
